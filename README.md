# Prem Kumar Thanneru — Portfolio

Personal portfolio website for **Prem Kumar Thanneru** — Actor, Director, Screenwriter & Editor.

## 🚀 How to Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `prem-portfolio`)
2. Upload all files keeping the folder structure:
   ```
   index.html
   images/
     img01.jpg
     img02.jpg
     ... (all 12 images)
   README.md
   ```
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)`
5. Click **Save** — your site will be live at:
   `https://YOUR_USERNAME.github.io/prem-portfolio/`

## 📁 File Structure
```
portfolio_site/
├── index.html       ← Main portfolio page
├── images/          ← All photos
│   ├── img01.jpg    ← Hero image
│   ├── img02.jpg    ← About section image
│   └── ...
└── README.md
```

## ✏️ Customization
- Open `index.html` in any text editor to edit text
- Replace images in the `images/` folder (keep same filenames)
- Update YouTube links in the Filmography section
